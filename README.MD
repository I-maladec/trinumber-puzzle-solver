# Tri-Number Puzzle Solver

## Description

Для вирішення задачі було вирішино створити цю програму. 

Як я прийшов до такого рішення:

Перше, що приходить на думку: треба взяти найбілший фрагмент як перший, і до нього приєднувати теж найбільші фрагменти.
Але одразу зрозуміло, що цей метод не робочий, оскільки не всі елементи з'єднуються, і, наприглад, у випадку якщо у нас є
наступні фрагменти
99-98-97
97-96-95
11-12-13
13-14-15
15-16-17
мИ отримуємо:
99-98-97-96-95
і
11-12-13-14-15-16-17 <- цей варіант білший

Подумавши про це, я зрозумів, що кількість розрядів важливіша за величину чисел в блоках, тому вирішил підприйняти таку логіку:
Алгоритм шукає найдовший "ланцюг" з блоків, і:
В першому випадку, де це дійсно найдовший ланцюг, це буде саме велике число, оскільки будь яке, число де
кількість розрядів n, буде більше ніж БУДЬ-яке число, де кількість розрядів m, при n > m (n=a×6, m=b×6, a>b)

В другому випадку, де ми знаходимо одинакові за довжиною ланцюги, ми порівнюємо вже значення отриманих з них чисел, і обираємо більший.

На базі цієї логіки, було створено програму, яка обчислює найдовший ланцюг за допомогою DFS-алгоритму:
Він викликає функцію dfs() для кожного блоку (початку), та яка рекурсивно викликається для кожного можливого для приєднання блоку,
аби продовжити ланцюг. Таким чином, алгоритм перебирає всі можливі ланцюги, які можно скласти з даних блоків, і зберігає
найдовший та найбільший знайдений з них у heaviest chain, до тих пір, поки не знайдеться ланцюг довше та більше,
або алгоритм не перебире всі можливі варіанти.

Для зручності розробки основного алгоритму було імплементовано об'єкт "puzlink" (puzzle+link), це саме наші блоки з трьох двозначних чисел.
Для зручності використання було додано невеличкий інтерфейс, де можна завантажити файл, та отримати результат у текстовому полі.
Задля запобігання блокування інтерфейсу, був використаний Worker.

Отриманий алгоритм, можливо, є не найефективнішим для вирішення даної задачі. Вірогідно, програму можна оптимізовувати та покращувати.

## Installation

1. Install [Node.js](https://nodejs.org/) (LTS recommended).
2. Clone this repository and open its directory:

	```bash
	git clone <repository-url>
	cd trinumber-puzzle-solver
	```

3. Install the dependencies:

	```bash
	npm install
	```

The program is now installed and ready to run:

```bash
npm run build
npx serve
```
